## 修正対象

rc15 独立監査で確認された VirusTotal authorization blocker 2系統を限定修正した。

### 1. 英語 comma 境界

否定文の comma を肯定 directive の境界として扱い、否定対象 IOC を authorize する問題を修正。

対象例:

```text
do not, under any circumstances, check 8.8.8.8 with VirusTotal
never, ever, check 8.8.8.8
please do not, for any reason, check 8.8.8.8
```

### 2. 日本語の肯定 action 部分一致

以下のような後続否定を無視し、「確認」「検索」「調べる」等だけを肯定と解釈する問題を修正。

```text
8.8.8.8をVTで確認するのはやめて
8.8.8.8を検索するのはやめて
8.8.8.8を調べてほしくない
8.8.8.8を確認してほしくない
```
